# LiteTools

面向魔兽世界正式服 12.1 的便捷工具集合。插件不依赖第三方运行库；本目录中的实现为本项目独立编写。

## 功能

- “删除物品自动输入 DELETE”：摧毁高品质物品或任务物品时自动填写 `DELETE`，但不会自动点击确认。
- “空格跳过动画”：播放过场动画或影片时，按空格键立即跳过。
- 分别设置默认经验条、声望条和荣誉条的宽度。
- “隐藏经验条”、“隐藏声望条”和“隐藏荣誉条”：分别控制三种状态条是否参与显示，不保留空白占位。
- “将眼睛固定在左侧”：固定微型菜单方向，使队列状态“眼睛”保持在菜单栏左侧。
- “鼠标放到时间上显示副本进度”：在小地图时钟提示中显示本周已锁定副本进度；结果由事件更新并缓存。
- “替换小地图边框”：使用插件内置的 `UIMinimap-ring.BLP` 替换默认边框，并随小地图尺寸自动缩放；可实时选择并永久保存边框颜色和透明度。
- “小地图顶部控件缩放”：同步调整追踪按钮、地图名称、时间、日历按钮及其背景和子材质的显示比例，不改变小地图圆盘大小。
- “小地图可移动”和“锁定位置”：勾选“小地图可移动”后可直接拖动小地图圆盘，位置自动保存；边框上的追踪、地点名称、时间和日历图标保持不动。勾选“锁定位置”后位置固定不可拖动。
- 打开商人界面时分批自动售卖背包中的灰色垃圾物品，关闭商人界面会立即停止。
- “自动修理”：打开可修理的商人时自动修理装备；可使用公会修理时优先使用公会资金，不足部分由个人金币补足。
- “隐藏子背包”：隐藏背包栏的展开按钮、4 个普通小背包按钮和材料包按钮，仅保留大背包按钮。
- “隐藏所有背包按钮”：隐藏展开按钮、大背包按钮和所有子背包按钮；取消后按“隐藏子背包”的当前设置恢复。
- “获得物品提示锚点”：勾选后显示锚点，左键拖动并自动保存位置，右键隐藏锚点但保持勾选和自定义布局；取消勾选后恢复暴雪官方位置。
- “Roll 装备列表锚点”：勾选后显示锚点，左键拖动并自动保存位置，右键隐藏锚点但保持勾选和自定义布局；取消勾选后恢复暴雪官方位置。
- “自动 Roll 装备”：显示需求、贪婪、分解、幻化和放弃批量操作面板；不可用时按优先级降级。“全都要”模式只显示一个大需求按钮，并为每件物品选择当前允许的最高级别。支持独立面板锚点、静音、自定义声音文件 ID 和 `/ltrollpreview`（简写 `/ltrp`）预览命令。该功能也可通过独立插件 `EMMM` 使用。
- “成就提示锚点”：勾选后显示锚点，左键拖动并自动保存位置，右键隐藏锚点但保持勾选和自定义布局；取消勾选后恢复暴雪官方位置。成就提示从已保存位置向上生长。
- “进入战斗提示”：进入战斗时根据角色阵营显示联盟或部落标题背景及居中的金黄色提示文字，并在设定的 1–3 秒总时长结束前渐隐。勾选后显示可永久保存位置的锚点，左键拖动、右键隐藏；支持 50%–200% 整体缩放。
- “离开战斗提示”：离开战斗时显示居中的绿色提示文字，联盟使用 `scoreboard-header-alliance`，部落使用 `scoreboard-header-horde`；两种背景均先去色再统一染成亮绿色。拥有独立的锚点、1–3 秒渐隐时长和 50%–200% 整体缩放。
- “战斗计时”：左侧以“小时:分钟:秒钟”显示副本或地下堡中的停留时间，进入时归零开始、离开时停表；右侧以“分钟:秒钟.两位毫秒”显示本次战斗时间，进入战斗时重置、离开战斗时停表。两个时间使用固定区域显示，中央 `|` 始终保持在框体中心。右键点击计时框会同时重置两个时间。计时框使用对应阵营的战斗标题背景，可左键拖动并永久保存位置，支持 50%–200% 缩放。
- “自定义动作条快捷键显示别名（只支持原生动作条）”：将原生动作条上的组合键、滚轮、数字键盘、翻页键和鼠标键显示为更紧凑的别名（如 SHIFT+E 显示为 S+E、鼠标滚轮向上显示为 MU），不改变实际按键绑定。

所有功能都集中在独立设置窗口中：左侧选择模块，右侧设置功能；可输入 `/lt` 或 `/litetools` 打开，也可从“选项 → 插件 → LiteTools”进入。窗口复用正式服家宅系统的选择地块列表、木质容器、花纹边框等 Atlas，设置仍然即时生效并保存在账号级 SavedVariables 中。升级时会自动把原 `FansWowToolsDB` 设置迁移到 `LiteToolsDB`，不会重置已有配置。

## 安装

将整个 `LiteTools` 文件夹复制到：

`World of Warcraft/_retail_/Interface/AddOns/`

随后重载界面或重新登录游戏。

从旧版 `FansWowTools` 目录升级时，请先退出游戏，并将账号目录中
`WTF/Account/<账号>/SavedVariables/FansWowTools.lua` 复制为同目录下的
`LiteTools.lua`。LiteTools 首次加载后会自动把其中的 `FansWowToolsDB`
迁移为 `LiteToolsDB`。本项目工作目录同步到游戏时已自动完成这一步。
