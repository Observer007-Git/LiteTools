# Fan's wow tools

面向魔兽世界正式服 12.0.7 的便捷工具集合。插件不依赖第三方运行库；本目录中的实现为本项目独立编写。

## 功能

- 摧毁高品质物品或任务物品时自动填写 `DELETE`，但不会自动点击确认。
- 播放过场动画或影片时，按空格键立即跳过。
- 分别设置默认经验条和声望条的宽度。
- 固定微型菜单方向，使队列状态“眼睛”保持在菜单栏左侧。
- 在小地图时钟提示中显示本周已锁定副本进度；结果由事件更新并缓存。
- 打开商人界面时分批自动售卖背包中的灰色垃圾物品，关闭商人界面会立即停止。

所有功能都可以在“选项 → 插件 → Fan's wow tools”中即时设置，设置保存在账号级 SavedVariables 中。

## 安装

将整个 `FansWowTools` 文件夹复制到：

`World of Warcraft/_retail_/Interface/AddOns/`

随后重载界面或重新登录游戏。
